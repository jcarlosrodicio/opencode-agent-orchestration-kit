# v1.0.36 - Safe lifecycle and canonical release identity

This release makes `/autonomous` choose a bounded iteration budget for the
specific local task instead of treating its six-iteration safety ceiling as a
target.

## Highlights

- `lead` records a task-specific planned iteration budget from one to six
  iterations before the workflow starts; six remains a hard safety ceiling.
- Durable loop state persists and enforces the selected budget, including after
  recovery. Schema migrations require explicit renewed approval before resume.
- Final reviewer approval stops the cycle immediately, so no additional action
  or iteration starts after successful closure.
- The packaged `oak state` command forwards the planned-iteration argument and
  the public contract checker rejects missing budget, ceiling, stop, or renewal
  guarantees.

## Installation or upgrade

For a new installation, preview the complete ownership plan before applying it:

```bash
./install.sh --dry-run
./install.sh
```

For an existing manifest-owned installation, preview and apply the upgrade:

```bash
./upgrade.sh --dry-run
./upgrade.sh
./doctor.sh
```

The supported runtime contract remains Node.js `^22.9.0 || ^24.0.0` with
OpenCode `>=1.14.41 <2.0.0`.

## Migration

The loop-state schema advances to v2. Existing v0 or v1 state must be migrated
explicitly with a newly selected budget and renewed human approval; previous
approval cannot resume migrated state.

## Validation performed

Release readiness covers the public and private contract checks, bundled
negative checker tests, loop-state and `oak` tests, installation smoke, exact
package smoke, canonical version/tag validation, and public leak scanning.
An end-to-end model transcript is not part of this deterministic release gate.

## Public safety boundary

The public release excludes private OpenCode configuration, local provider and
MCP wiring, credentials, authentication files, raw transcripts, private
evidence, user-specific absolute paths, machine-local state, and private
specification or planning documents. Local provider, search, and MCP
integrations are not part of this release.
