# v1.1.1 - Safe lifecycle and canonical release identity

This patch release makes the session evidence collector work on large
OpenCode databases. It loaded every stored part and, in full-rescan mode,
every message body, although it only reads message roles and text parts. Tool
output is most of a real database, so on large databases the export alone
passed the collector's 300-second sqlite3 limit, and exact-root collection and
`collect-session-evidence --run` always failed there.

## Highlights

- The collector queries select only message roles and text parts, on both
  OpenCode 1 and OpenCode 2 databases. On a database with 410 MB of part data,
  collecting one execution tree went from a timeout to about ten seconds, and
  the resulting trees are identical to the previous collector's output.
- The documented publish command uses `./dist/<name>.tgz`: without the leading
  `./`, npm reads the path as a GitHub `owner/repo` shorthand.

## Installation or upgrade

Install or upgrade the published CLI package:

```bash
npm install --global opencode-agent-orchestration-kit@1.1.1
oak version
oak upgrade --dry-run
oak upgrade
```

The npm installation exposes the CLIs but does not mutate OpenCode
configuration. `oak install` and `oak upgrade` remain separate, explicit
operations.

## Migration

No migration is required. Existing harness configuration remains compatible.

## Validation performed

The public contract check, unit and script suite, typechecks for OpenCode 1
and OpenCode 2, compatibility and supply-chain checks, installation smoke and
package smoke passed. GitHub Actions Check was green on the merged pull
request before the release tag.

## Public safety boundary

The public release excludes private OpenCode and Pi configuration, local
providers and MCP wiring, credentials, authentication files, provider URLs,
raw transcripts, private evidence, absolute machine-local paths, and runtime
state. The database measurements behind this change stayed private: no model
names, session identifiers, or local database paths reached this repository.

Boundary statement: no private config, no credentials, no provider URLs, no
raw transcripts, no machine-local paths.
