# v1.0.44 - Safe lifecycle and canonical release identity

This patch release ships two latency changes measured against real session
history rather than inferred from the contracts: the four review specialists
now run in parallel, and `lead` forwards the researcher handoff verbatim
instead of re-synthesizing it before `specifier`. It also ignores the `.tgrep`
local index, which stored absolute machine paths in a public checkout.

## Highlights

- Run `--full-agents` review specialists in parallel instead of sequentially.
  The deferred "real concurrency" guarded a hazard the design cannot have:
  every specialist is `mode: subagent` with `edit: deny`, reads only its
  disjoint `manifest.reviewer_patch_sets[reviewer]` entry, and returns findings
  in its response, so there is no concurrent writer and no shared file to
  collect. `reviewer_timeout_ms` stays per reviewer, but because the reviewers
  overlap the total clock now tends to the slowest one rather than the sum.
- Stop `lead` re-synthesizing research. `researcher` delimits its specifier
  handoff with `BEGIN_SPEC_INPUT`/`END_SPEC_INPUT` and writes it
  self-contained; `lead` forwards it verbatim and adds only the validated
  objective, scope and out of scope, accepted assumptions, and the designer
  handoff. `specifier` is told the block arrives unsummarized, so an incomplete
  block is a research blocker rather than a gap to fill by assuming.
- Pin both contracts with six assertions in `opencode/scripts/check-harness.mjs`
  so neither drifts back, and add a prepare test asserting the execution plan
  instructs parallel execution.
- Ignore `.tgrep/`, a regenerable local search index that stores absolute paths
  from the machine that built it and was untracked and unignored.

## Installation or upgrade

Install or upgrade the published CLI package:

```bash
npm install --global opencode-agent-orchestration-kit@1.0.44
oak version
oak install --dry-run
oak install
```

The npm installation exposes the CLIs but does not mutate OpenCode
configuration. `oak install` remains a separate, explicit operation.

## Migration

No migration is required. Existing harness configuration remains compatible.
`--full-agents` keeps its explicit opt-in and its four-reviewer cap; only the
execution order changes. Real cancellation of a reviewer that exhausts its
budget is still absent: it is reported `timed_out`, but its turn is allowed to
finish.

## Validation performed

The public contract check, unit and script suite, tag/version identity check,
`git diff --check`, and package smoke passed. GitHub Actions Check was green on
both merged pull requests before the release-prep commit.

## Public safety boundary

The public release excludes private OpenCode and Pi configuration, local
providers and MCP wiring, credentials, authentication files, provider URLs,
raw transcripts, private evidence, absolute machine-local paths, and runtime
state. The session measurements behind these changes stayed private: no model
names, session identifiers, or local database paths reached this repository.

Boundary statement: no private config, no credentials, no provider URLs, no
raw transcripts, no machine-local paths.
